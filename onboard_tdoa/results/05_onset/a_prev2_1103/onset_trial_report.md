# onset 帧筛选试验报告（REC_016 / REC_018，interp 8）

## 能量定义与公式

- VAD / onset 用的帧能量 = `_frame_energy` = `(MIC1·MIC1 + MIC2·MIC2) / (2N)` = **均方 = 功率**（无开方）。
- 因此 onset 阈值倍数用 **功率公式 `10^(onset_db/10)`**。
- onset 规则：一帧保留 = 原本 voiced==1 且 `energy[i] >= energy[i-2] * 10^(onset_db/10)`（i-2 = 帧移 2 次前的不重叠帧）。段开头前两帧无 i-2 → onset=0。角度/τ/conf 统计只用 onset==1 的帧。
- 分析参数未改：噪声底、VAD 门槛、帧长 64ms、帧移 32ms、interp=8、频带均为原值。
