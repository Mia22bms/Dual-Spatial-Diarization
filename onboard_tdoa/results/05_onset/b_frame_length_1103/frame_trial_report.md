## 帧长参数确认

`single_board_doa.py` 已有帧长参数 `--frame-ms`、帧移参数 `--hop-ms`；FFT 点数由代码自动推导（`1<<ceil(log2(2N))`）。未改代码。

## 与 SPEC 不一致 / 没把握处

1. WAV 扩展名大写 `.WAV`，带入文件名 tag。
2. 帧长变小 → 帧移随之减半（32→hop16、16→hop8），保留"帧移=帧长一半"；每种帧长噪声底、VAD 门槛、FFT 点数随帧长不同（见上表），这是代码现有设定的自然结果，未改任何规则。
3. onset=3 在 16/32 ms 下保留帧数仍较多（最少 REC_016 1m/32ms = 57 帧），无极端少帧问题。
4. 帧长缩短使角度 p25/p75 区间普遍变宽（如 REC_016 1.5m/16ms p25 降到 4.27），分散度增大。
