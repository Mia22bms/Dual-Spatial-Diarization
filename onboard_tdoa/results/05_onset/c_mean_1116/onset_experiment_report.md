# onset 帧筛选实验报告（REC_016 / REC_018，interp 8 + 抛物线拟合）

## onset 规则与默认值

- 帧能量 = `(MIC1·MIC1 + MIC2·MIC2)/(2N)` = 均方 = **功率**。
- **一帧保留（onset=1）= 原本 voiced 且 `energy[i] ≥ mean(energy[i-lookback:i]) × 10^(onset_db/10)`**，
  即短时能量相对**前 `lookback` 帧的平均**上升 ≥ `onset_db` dB。段开头不足 `lookback`
  帧的无法回看 → onset=0。统计（角度中位数/百分位）只用保留帧。
- 两个新参数与默认值（命令行 `--onset-db` / `--onset-lookback`）：
  - **`onset_db` 默认 6.0 dB**（功率上升 4×，作为“明显上升”门槛）
  - **`onset_lookback` 默认 3 帧**（64 ms/hop32 下回看约 96 ms，含上一帧及两帧不重叠历史）
- 本实验三种设置全部 `interp=8` + `--parabolic`（抛物线亚采样细化）。
  帧移沿用现有“帧移=帧长一半”：64 ms→hop 32 ms，16 ms→hop 8 ms。

## 与 spec / 既往不一致、没把握处

1. **onset 回看定义和既往报告不同**：本次按本任务要求把回看长度做成参数，比较对象改为
   “前 `lookback` 帧的**平均**功率”。既往 `onset_trial_report.md` / `frame_trial_report.md`
   用的是固定“单帧 `energy[i-2]`”。因此同名 `--onset-db` 下保留帧数/中位数与旧报告不可直接对比。
2. **帧数阈值的代表性**：(c) onset+f16 多段保留帧极少——REC_016 1m 仅 3 帧、1.5m 仅 4 帧，
   REC_018 1m 5 帧；其中位数/百分位代表性低。REC_016 1.5m 的 (c) 中位数 43.55° 明显跳高
   （对比 (a) 15.54°、(b) 20.18°），几乎肯定是 4 帧样本偶然，不宜解读为趋势。
3. **趋势**：onset 筛选（(a)→(b)）在所有段都把角度中位数推高、更偏 MIC1 一侧
   （远段更明显，如 REC_018 1m 27.54°→37.44°）；这是筛选高能起始帧的结果，未调参。
4. WAV 扩展名为大写 `.WAV`，与早期 `REC_015.wav` 命名风格不一致（沿用既往现象）。
5. 平均曲线图的“归一化”取**每帧除以自身峰值**；若改成别的归一化（如除以频带能量）
   曲线形状会不同——此处为一种合理选择，已写明。
6. 全部段角度中位数为正、无接近 0°（正前方）的结果，与既往距离测试报告一致，录音几何需你确认
   （非本次改动引入）。
