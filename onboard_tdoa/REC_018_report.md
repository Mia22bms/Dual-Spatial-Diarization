## 6. 与 SPEC 不一致 / 没把握处

1. WAV 扩展名为大写 `.WAV`，输出 tag 也带入；与早期 `REC_015.wav` 命名风格不同。
2. 所有段角度中位数均为正（偏 MIC1 一侧），无接近 0°（正前方）的结果；距离测试若预期声源在正前方，与此不符，需确认录音几何。
3. 距离越远 conf 越低、角度中位数越小（0.3m→1m：i8 48.10°→26.53°），且高/低 conf 两组角度中位数差随距离拉开——需你判断是否符合预期。
4. 输出 CSV 无能量列，故本报告未含能量统计（沿用 REC_016 做法）。
